Restock alerts

Sold out shouldn’t mean lost sale.

Drop a small form on any product page. When the item is really back in stock, each customer who asked gets one beautiful email. Not zero, not two.

Open the form Embed it on your store

Live preview

Verified restocks only

Webhooks are treated as hints. Every restock is confirmed with the stock API before anyone is emailed.

Exactly one email

Duplicate deliveries, retries and restarts can’t double-send: each request is claimed once and sent with a stable idempotency key.

Nothing slips through

Failed sends retry with backoff, and a reconciler sweeps for restocks whose webhook never arrived.

Embed it

Paste this where the “Add to cart” button would be. Set sku to hide the SKU field; product, accent (hex) and theme (light, dark, auto) are optional.

<iframe src="{{ base_url }}/embed?sku=ABC-1&product=Linen%20Overshirt"
        title="Get notified when it's back" style="width:100%;max-width:520px;height:300px;border:0"
        id="back-in-stock"></iframe>
<script>
  // Optional: let the form size itself.
  addEventListener("message", function (e) {
    if (e.data && e.data.type === "back-in-stock:resize")
      document.getElementById("back-in-stock").style.height = e.data.height + "px";
  });
</script>

Endpoints

GET /embedSignup form, designed to live in an iframe.
POST /api/requests{"email", "sku"} as JSON. Returns 201 for a new request, 200 with already_subscribed for a duplicate.
POST /webhooks/stockStock events with the X-Webhook-Secret header.
GET /adminRequests, delivery status and webhook outcomes (password protected).
GET /healthzLiveness check.
